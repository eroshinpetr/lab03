# Отчёт по лабораторной работе №3

## Тема
Изучение систем автоматизации сборки проекта на примере CMake.

## Цель работы
Освоить основы автоматизации сборки C++-проекта при помощи CMake, научиться описывать библиотеки и приложения в `CMakeLists.txt`, а также настраивать зависимости между отдельными частями проекта.

## Постановка задачи
В рамках homework требовалось:
1. Создать `CMakeLists.txt` для статической библиотеки `formatter_lib`.
2. Создать `CMakeLists.txt` для библиотеки `formatter_ex_lib`, использующей библиотеку `formatter`.
3. Создать `CMakeLists.txt` для приложений:
   - `hello_world_application`, использующего `formatter_ex`;
   - `solver_application`, использующего `formatter_ex` и `solver_lib`.
4. Выполнить сборку проекта и проверить корректность работы приложений.

## Ход работы

### 1. Подготовка структуры проекта
В рабочий репозиторий были добавлены директории:
- `formatter_lib`
- `formatter_ex_lib`
- `solver_lib`
- `hello_world_application`
- `solver_application`

Также был создан корневой файл `CMakeLists.txt`, который подключает все подпроекты через `add_subdirectory(...)`.

### 2. Создание CMake-конфигурации для библиотек

#### formatter_lib
Для директории `formatter_lib` был создан `CMakeLists.txt`, в котором:
- объявлена статическая библиотека `formatter`;
- подключена текущая директория как публичная include-директория.

#### formatter_ex_lib
Для директории `formatter_ex_lib` был создан `CMakeLists.txt`, в котором:
- объявлена статическая библиотека `formatter_ex`;
- настроено подключение заголовочных файлов;
- добавлена линковка с библиотекой `formatter`.

#### solver_lib
Для директории `solver_lib` был создан `CMakeLists.txt`, в котором:
- объявлена статическая библиотека `solver_lib`;
- подключена директория с заголовочными файлами.

### 3. Создание CMake-конфигурации для приложений

#### hello_world_application
Для приложения `hello_world` был создан `CMakeLists.txt`, в котором:
- объявлен исполняемый файл `hello_world`;
- выполнена линковка с библиотекой `formatter_ex`.

#### solver_application
Для приложения `solver` был создан `CMakeLists.txt`, в котором:
- объявлен исполняемый файл `solver`;
- выполнена линковка с библиотеками `formatter_ex` и `solver_lib`.

### 4. Сборка проекта
Для сборки проекта использовались команды:

```bash
cmake -S . -B build
cmake --build build
```
